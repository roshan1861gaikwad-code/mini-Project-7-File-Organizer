# 📁 Smart File Organizer

A beginner-friendly Python automation project that organizes files into folders based on their file extensions.

## ✨ Features
- Automatically sorts images, documents, videos, audio, and code files.
- Creates destination folders automatically.
- Prevents overwriting files with duplicate names.
- Handles file-operation errors.
- Leaves unsupported file types untouched.

## 🛠️ Technologies
- Python 3
- `pathlib`
- `shutil`

## ▶️ How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run:

   ```bash
   python main.py
   ```

5. Enter the path of the folder you want to organize.
